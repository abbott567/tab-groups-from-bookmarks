# Security policy

## Supported versions

Security fixes are only made to the latest version of Tab Groups from Bookmarks.

## Report a security problem

Do not report security problems in a public issue.

Instead, [report it privately on GitHub](https://github.com/abbott567/tab-groups-from-bookmarks/security/advisories/new). You can also go to the **Security** tab of this repository and select **Report a vulnerability**. You need a GitHub account to do this.

In your report, include:

- what the problem is, and what someone could do with it
- the steps to reproduce it
- the versions of the extension and Chrome you used

Only you and the maintainer can see the report. You will get a reply as soon as possible, and you will be told when the problem is fixed.
